# Contributing

Guides and manual pages live in the engine repository, in its `docs/` folder, so they are updated in the same pull
requests as the code they describe. The site itself (theme, home page, these contributing pages and the API
reference tooling) lives in the [docs repository](https://github.com/ATMO-Engine/docs).

Read [[writing-documentation]] before opening a pull request, and [[versioning]] to know how pages reach each
version of the site.
