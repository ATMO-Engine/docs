Getting started ​

ATMO is a lightweight, cross-platform 2D game engine written in C++23. It is built around an Entity Component System (ECS) and uses Luau for scripting.

  • New to the engine? Start by building it from source.
  • Want to understand how it fits together? Read the Architecture overview overview.
  • Looking for a class or function? Browse the C++ API reference.
