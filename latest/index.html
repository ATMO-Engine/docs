Code

Script in Luau. Extend in C++.

Gameplay lives in small Luau scripts attached to entities. When you need more, an addon compiles to a native library loaded by the editor.

move_sprite.luau

luau
function Update(deltaTime)
    local transform = this:getTransform()
    if transform == nil then return end

    if Input.isPressed("D") then
        transform.position.x = transform.position.x + 100 * deltaTime
    end

    if Input.isPressed("Q") then
        transform.position.x = transform.position.x - 100 * deltaTime
    end
end

From assets/script/move_sprite.luau in the engine repository.
