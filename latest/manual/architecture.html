Architecture overview ​

ATMO is a C++23 cross-platform 2D game engine built around an Entity Component System using Flecs.

The engine ​

core::Engine owns the main loop. It initializes SDL, input and logging, then drives the ECS world every frame. Entities are created and destroyed through the EntityRegistry, and every scene is rooted in a ecs::entities::Scene entity that manages the lifecycle of its children.

Core systems ​

SystemResponsibility
ResourceManagerHandle-based loading and caching of images, fonts and scripts
InputManagerKeyboard, joystick and controller input through SDL3
EventRegistryObserver-style event dispatch
ProjectManagerReads .atmo project files and mounts the virtual file system
MetaRegistryRuntime type information used for serialization and the editor

Addons ​

Addons are declared with an addon.json manifest. An Addon whose atmo_version does not match the running engine is rejected with Addon::AddonLoadException. Addons may ship a native library exporting an entry point declared with ATMO_REGISTER_ADDON, which receives an AtmoAPI giving access to the engine's core systems.

To keep this page accurate, every symbol above is a reference checked at build time: see References.
