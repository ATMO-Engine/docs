User interface ​

UI entities draw over the game, in window coordinates: the camera does not move them.

Limits

The UI system is used by the editor and is not finished for games:

  • Scripts cannot read or change UI entities, or know that a button was pressed.
  • Most layout options cannot be changed in the inspector, and some are not stored in scene files.
  • Scenes with some of the widgets cannot be opened again.

Show a label ​

  1. In the scene editor, add a UIRect to the scene, and a UILabel inside it.
  2. Select the label and write its text.
  3. Press Play: the scene editor does not show UI entities.

The other UI types in the list belong to the editor.

A UI entity must be the child of another UI entity, or of an entity that is not UI, in which case it is placed from the top-left corner of the window. Several UI entities directly in the scene are placed side by side.

UI ​

Every UI entity has this component:

FieldDefaultDescription
visibleYesHides the entity and its children. Ignored on UI entities placed directly in the scene.
modulateWhiteTint. For a label, the color of the text.

Layout ​

Layout sets the size of an entity and the place of its children, which are in a row. The inspector shows its fields but cannot change them. Write them in the scene file:

json
"Layout": {
    "width": { "type": 2, "size": { "min": 200, "max": 200 } },
    "height": { "type": 0, "size": { "min": 0, "max": 0 } },
    "padding": { "left": 8, "right": 8, "top": 8, "bottom": 8 },
    "gap": 4,
    "floating": { "enabled": false, "offset": { "x": 0, "y": 0 } }
}
FieldDescription
widthSize on the horizontal axis
heightSize on the vertical axis
paddingSpace between the edges and the children, in pixels
gapSpace between two children, in pixels
floatingWhen enabled, places the entity at offset from the top-left corner of the window, over the rest

Sizes ​

typeNameSize of the entitysize
0FitThat of its contentsmin and max, where 0 is no limit
1GrowThe space left by the othersmin and max, where 0 is no limit
2Fixedmin pixelsThe same min and max
3PercentA part of its parentA number from 0 to 1

The direction (horizontal), the alignment of the children, the aspect ratio, the scrolling and the depth order are not stored in scene files.

Button ​

FieldDefaultDescription
toggleNoThe button stays pressed until it is pressed again

C++ code can connect to the signals of a button: see Signals of UI entities.

Text fields ​

UIInput and its variants have these fields: text, placeholder, input_type (0 text, 1 integer, 2 decimal, in the scene file only), multiline, read_only, password, max_length and font_size (in the scene file only, 0 for no limit), font_path, text_color and placeholder_color.

Known issues ​

  • A scene or prefab saved with a UICheckBox, a UISlider, a UiDropdownMenu or a UIFoldableTreeItem makes the engine crash when it is loaded. These widgets create their own children, which are saved with the scene and then created twice. If a scene is already affected, remove the children of the widget from the file with a text editor.
  • The default font is missing from exported games, unless the project contains it: see Before exporting.
